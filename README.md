# Hogwarts Academy — TypeScript Mini Project

Projet TAF : Generics, Utility Types, Type Guards et Method Decorators.

## Prérequis
- Node.js 18+
- npm

## Installation
```bash
npm install
```

## Exécution
```bash
npm start
```

## Vérification TypeScript
```bash
npm run typecheck
```

## Exercices inclus
1. Ajouter un Wizard sans fournir l'ID (`Omit`, ID généré automatiquement).
2. Filtrer les Wizards par maison.
3. Extraire les événements `spell-cast` avec `Extract`.
4. Valider la puissance d'un sort avec un décorateur.
5. Mettre en cache les résultats d'une méthode synchrone avec `Map`.
6. Renforcer le Type Guard pour valider les quatre maisons autorisées.

Le projet utilise l'API legacy des décorateurs TypeScript et active `experimentalDecorators`.
